# 🍴 Food Ordering Application

This is a **Food Ordering Application**.  

- 🖥️ **Backend**: Built using **Spring Boot**  
- 🌐 **Frontend**: Built with **React**  
- 🚀 **Deployment**:  
  - The **Frontend** is deployed on Google Cloud Run and can be accessed here:  
    👉 [React Frontend](https://react-frontend-134213214273.us-central1.run.app/)  
  - The **Backend** is deployed as a separate Google Cloud Run service  
- 📂 **Database**: Firestore (Firebase)
